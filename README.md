# JARVIS Control Center

Central control repository for Ismail's business automation stack.

## Connected systems
- ChatGPT — command and orchestration layer
- GitHub — code and project management
- Supabase — database/backend
- Google Drive — files and media
- Adobe — creative workflow
- Metricool — social publishing and analytics
- Windsor.ai / Meta Ads — advertising data and actions

## Managed projects
- Orgunlar Garage
- Garantili Arabam / Oto Ekspertiz
- ChipPower Cyprus
- Oto Market Kibris

## Operating rules
1. Never modify production projects or spend advertising budget without an explicit task.
2. Destructive, financial, publishing, and production changes require confirmation before execution.
3. Prefer read-only status checks for the command: "Jarvis durum nedir?"
4. Keep credentials and secrets out of this repository.
5. Existing business repositories remain independent from this control repository.

## Status command
"Jarvis durum nedir?" means: gather available live status from connected services and return a concise Turkish summary of projects, social publishing, advertising, and any issues requiring attention.
