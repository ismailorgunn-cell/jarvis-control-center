# JARVIS Commands

## Jarvis durum nedir?
Read connected systems and summarize:
- active projects and obvious failures
- scheduled/published social content when available
- Meta Ads status/spend when available
- items that need Ismail's attention

## Jarvis <project> durum
Inspect only the named project.

## Jarvis <task>
Route the task to the relevant connected service. Prepare risky/spend/publish/destructive actions first and request confirmation before execution.
