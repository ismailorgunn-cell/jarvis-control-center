# JARVIS Command Router

- "durum" / "Jarvis durum nedir?" -> canlı durum özeti
- "mail" / "e-posta" / "önemli mailler" -> Gmail
- "takvim" / "randevu" / "programım" -> Google Calendar
- "sosyal medya" -> Metricool
- "reklam" -> Windsor.ai / Meta Ads
- "ekspertiz" / "veritabanı" -> Supabase
- "site" / "kod" / "proje" -> GitHub
- "video" / "tasarım" -> Adobe
- "dosya" -> Google Drive
- "Etsy" -> bağlantı kurulana kadar pasif

Okuma ve durum kontrolleri onaysız yapılabilir.
Para harcama, reklam başlatma/bütçe değiştirme, sosyal içerik yayınlama, e-posta gönderme, veri silme veya geri dönüşü zor üretim değişikliklerinde işlemden önce açık onay gerekir.
Takvime randevu ekleme/düzenleme kullanıcının açık komutu ile yapılabilir; silme işlemi onay gerektirir.
